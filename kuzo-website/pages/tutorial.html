Hello World

Every Kuzo program starts with a main function. Let's create your first program.

Running kuzo init myapp creates a new project with src/Main.kz as the entry point.

bash

kuzo init myapp
cd myapp
kuzo run

src/Main.kz

fun main(): void {
    println("Hello, Kuzo!")
}

The fun keyword declares a function. main is the entry point — it takes no arguments and returns void. println prints a line to stdout.

Tip

Run kuzo run to compile and execute in one step.

Variables & Types

Kuzo is statically typed. Use val for immutable bindings and var for mutable ones.

val name: str = "Kuzo"
val version: i32 = 1
var counter: i32 = 0
counter = counter + 1

Type annotations are required on declarations. Once a val is assigned, it cannot be reassigned. var allows mutation.

Kuzo provides a rich set of primitive types:

val a: i8 = 127
val b: i16 = 32767
val c: i32 = 2147483647
val d: i64 = 9223372036854775807i64
val e: u8 = 255
val f: u16 = 65535
val big: i128 = 42i128
val pi: f64 = 3.14159
val half: f32 = 0.5f32
val ch: char = 'A'
val active: bool = true

Integer types include i8 through i128 (signed) and u8 through u128 (unsigned). Float types include f16, f32, f64, and f128. The char type represents a single Unicode character.

Tip

Type suffixes like 42i64 or 3.14f64 specify the exact type of a literal.

Integer Overflow

Integer arithmetic uses wrapping semantics — overflow wraps around to the minimum or maximum value.

val max: i32 = 2147483647
val wrapped = max + 1  // -2147483648 (wraps to MIN)

val u_max: u8 = 255
val u_wrapped = u_max + 1  // 0 (wraps around)

Float Special Values

Floats support Inf, -Inf, and NaN following IEEE 754:

val inf: f64 = 1.0f64 / 0.0f64
val neg_inf: f64 = -1.0f64 / 0.0f64
val nan: f64 = 0.0f64 / 0.0f64

// NaN never equals itself
val check = nan != nan  // true

Number Literals

val hex = 0xFF       // 255
val bin = 0b1010     // 10
val oct = 0o777      // 511

Functions

Functions are declared with fun. The last expression is the return value — no return keyword needed.

fun add(a: i32, b: i32): i32 {
    a + b
}

fun greet(name: str): void {
    println("Hello, {name}!")
}

add returns the result of a + b without an explicit return keyword. Functions returning void use println or other side effects. This is called expression-based returns.

Calling functions

val sum = add(3, 4)
greet("World")

Functions can be recursive:

fun fib(n: i32): i32 {
    if n < 2 { n } else { fib(n - 1) + fib(n - 2) }
}

Control Flow

Kuzo supports if/else conditionals and match expressions. Both are expressions — they return values.

if / else

fun classify(n: i32): str {
    if n > 0 { "positive" }
    else if n < 0 { "negative" }
    else { "zero" }
}

if is an expression. You can assign its result directly:

val sign = if 5 > 3 { 1 } else { -1 }

Block expressions evaluate to their last expression:

val result = {
    val a = 3
    val b = 4
    a + b
}

A block expression { ... } evaluates every statement and returns the value of the last expression. This is useful for scoping intermediate variables.

match

fun describe(n: i32): str {
    match n {
        0 => "zero"
        1 => "one"
        _ => "many"
    }
}

match selects the first matching arm. _ is a wildcard that matches anything.

Loops

Kuzo provides while loops with break and continue, plus for-in iteration.

while

var i: i32 = 0
var sum: i32 = 0
while i < 10 {
    sum = sum + i
    i = i + 1
}

while repeats as long as the condition is true. Use break to exit early and continue to skip to the next iteration.

var n: i32 = 0
while n < 100 {
    if n >= 5 { break }
    n = n + 1
}

for-in

val arr = [10, 20, 30, 40]
var total: i32 = 0
for x in arr.iter() {
    total = total + x
}

for x in arr.iter() iterates over array elements. Loops can be nested arbitrarily.

Tip

break only exits the innermost loop — outer loops continue normally.

Arrays

Arrays hold ordered sequences of values. Create them with square brackets.

val nums = [1, 2, 3, 4, 5]
val first = nums[0]
val last = nums[nums.len() - 1]

Access elements by index (0-based). .len() returns the array length.

Concatenate arrays with ++:

val a = [1, 2]
val b = [3, 4]
val c = a ++ b

++ creates a new array — the originals are unchanged. This is a deep copy, not a mutation.

val strs = ["hello", "world"]
val nested = [[1, 2], [3, 4]]
val grid = nested[0][1]

Arrays can hold any type, including strings, records, and other arrays.

val empty: i32[] = []
val built = empty ++ [1, 2, 3]

Tip

Use explicit type annotations (i32[]) for empty arrays since the compiler can't infer the element type.

Closures

Closures are anonymous functions that capture their surrounding scope. Create them with fun without a name.

val x: i32 = 10
val read = fun() { x }
val result = read()

Closures capture variables by reference. A closure can read and modify var bindings:

var count: i32 = 0
val inc = fun() { count = count + 1 }
inc()
inc()
inc()

After three calls, count is 3. Changes inside the closure are visible outside.

Closures can escape their defining scope and maintain state:

fun makeCounter(): (() -> i32) {
    var n: i32 = 0
    fun() {
        n = n + 1
        n
    }
}

val c = makeCounter()
val a = c()
val b = c()

Each call to makeCounter creates an independent counter. The function type () -> i32 describes a closure that takes no arguments and returns an i32.

Closures are first-class values — pass them as arguments and return them:

fun apply(f: (() -> i32)): i32 { f() }
fun compose(f: (() -> i32), g: (() -> i32)): (() -> i32) {
    fun() { f() + g() }
}

Tip

Function types use the arrow syntax: (A, B) -> C for a function taking A and B, returning C.

Closures can take parameters and capture multiple variables:

val base: i32 = 100
val adder = fun(n: i32) { base + n }

val r1 = adder(5)   // 105
val r2 = adder(50)  // 150

Closures are first-class — store them in arrays and iterate:

var fns: (() -> i32)[] = []
var i: i32 = 0
while i < 3 {
    val captured = i * 10
    fns = fns ++ [fun() { captured }]
    i = i + 1
}
// fns[0]() = 0, fns[1]() = 10, fns[2]() = 20

Closures can return other closures, enabling factory patterns:

fun makeAdder(n: i32): (() -> i32) {
    fun() { n + 1}
}

val add5 = makeAdder(5)
val result = add5()  // 6

Generics

Generics let you write functions that work with any type.

fun identity<T>(x: T): T {
    x
}

val n = identity<i32>(42)
val s = identity<str>("hello")

The type parameter T can be any type. The compiler ensures type safety at each call site.

fun double_cast<T>(x: T): T {
    cast(cast(x).to(f64)).to(T)
}

Generics support multiple type parameters and generic types:

fun swap<T, U>(a: T, b: U): (U, T) {
    Pair(b, a)
}

type GList<T> = | GNil | GCons(T, GList<T>)

fun glen<T>(l: GList<T>): i32 {
    match l {
        GNil => 0
        GCons(_, t) => 1 + glen(t)
    }
}

Generic functions can call other generic functions, and the compiler monomorphizes each instantiation for full type safety.

Custom Types

Kuzo has two ways to define custom types: algebraic data types (ADTs) for tagged unions, and records for grouped fields.

Algebraic Data Types

type Shape = | Circle(f64) | Rect(f64, f64)

fun area(s: Shape): f64 {
    match s {
        Circle(r) => 3.14159 * r * r
        Rect(w, h) => w * h
    }
}

An ADT lists its variants after |. Pattern matching destructures each variant.

Records

type Point = Point(x: i32, y: i32)

val p = Point(3, 4)

Records group named fields. Construct by calling the type name with field values in order.

Records support nullable fields, array fields, and mutation with var:

type User = User(name: str, age: i32?, tags: str[])

val u1 = User("Alice", 30, ["admin"])
val u2 = User("Bob", null, [])

val age = u1.age ?? 0  // 30
val tagCount = u2.tags.len()  // 0
var pt = Point(0, 0)
pt.x = 10  // mutate field via var
pt.y = 20

Records can be destructured in match with guards:

fun quadrant(p: Point): str {
    match p {
        Point(0, 0) => "origin"
        Point(x, y) if x > 0 && y > 0 => "Q1"
        Point(x, y) if x < 0 && y > 0 => "Q2"
        Point(_, 0) => "x-axis"
        _ => "other"
    }
}

Recursive Types

type Tree = | Leaf | Node(i32, Tree, Tree)

fun treeSum(t: Tree): i32 {
    match t {
        Leaf => 0
        Node(v, l, r) => v + treeSum(l) + treeSum(r)
    }
}

val tree = Node(1, Node(2, Leaf, Leaf), Node(3, Leaf, Leaf))

ADTs can be recursive — a Tree variant can contain other Tree values. This is ideal for linked structures like trees and linked lists.

Pattern Matching

Pattern matching goes beyond simple value comparison. Kuzo supports or-patterns, guards, nested destructuring, and literal matching.

Or-Patterns

fun weekend(n: i32): bool {
    match n {
        0 | 6 => true
        _ => false
    }
}

Use | to match multiple patterns in a single arm.

Guards

fun classify(n: i32): str {
    match n {
        n if n < 0 => "negative"
        n if n % 2 == 0 => "even"
        _ => "odd"
    }
}

Guards add a boolean condition with if. The arm only matches if the guard is true.

Nested Destructuring

type Pt = Pt(x: i32, y: i32)
type Seg = Seg(a: Pt, b: Pt)

fun segLen(s: Seg): i32 {
    match s {
        Seg(Pt(x1, y1), Pt(x2, y2)) => (x2 - x1) + (y2 - y1)
    }
}

Patterns can nest arbitrarily deep, destructuring records inside records.

Literal Patterns

fun command(cmd: str): i32 {
    match cmd {
        "go" | "move" | "run" => 1
        "stop" | "halt" => 2
        _ => 0
    }
}

fun vowel(c: char): bool {
    match c {
        'a' | 'e' | 'i' | 'o' | 'u' => true
        _ => false
    }
}

Match on string and char literals. Combine with or-patterns for multi-value matching.

Tip

Wildcards (_) ignore parts of a structure. Use Node(v, _, _) to extract only the value from a tree node.

Traits

Traits define shared behavior. Types implement traits to provide methods. A trait declares method signatures; types provide implementations.

trait Show {
    fun show(self): str
}

type Point: Show = Point(x: i32, y: i32) {
    fun show(self): str {
        "Pt(" + cast(self.x).to(str) + "," + cast(self.y).to(str) + ")"
    }
}

The trait keyword declares a trait. A type implements it by listing the trait name after : and providing method bodies inside { }. Methods take self as the receiver.

Types can implement multiple traits:

trait Greet {
    fun name(self): str
    fun hello(self): str {
        "Hello, " + self.name()
    }
}

trait Sizeable {
    fun sz(self): i32
}

type Ordering: (Greet, Sizeable, Show) = | Lt | Eq | Gt {
    fun name(self): str {
        match self {
            Lt => "less"
            Eq => "equal"
            Gt => "greater"
        }
    }
    fun sz(self): i32 {
        match self { Lt => -1; Eq => 0; Gt => 1 }
    }
    fun show(self): str {
        "Ordering." + self.name()
    }
}

List multiple traits in parentheses: (Greet, Sizeable, Show). The hello method has a default implementation — types only need to implement name, and hello works automatically.

Tip

Default methods can call other trait methods. hello calls self.name(), which each type implements differently.

Default methods can chain — one default calls another, creating multi-layer behavior:

trait Chain {
    fun base(self): str
    fun wrap1(self): str {
        "[" + self.base() + "]"
    }
    fun wrap2(self): str {
        "{{" + self.wrap1() + "}}"
    }
}

type Tag: Chain = Tag(label: str) {
    fun base(self): str {
        self.label
    }
}

val t = Tag("hi")
// t.wrap1() = "[hi]"
// t.wrap2() = "{{[hi]}}"

Trait methods can take extra parameters beyond self, and can return new instances for chaining:

trait Counter {
    fun current(self): i32
}

type CounterBox: Counter = CounterBox(count: i32) {
    fun current(self): i32 { self.count }
    fun next(self): CounterBox {
        CounterBox(self.count + 1)
    }
}

val c = CounterBox(0)
val three = c.next().next().next()
// three.current() = 3

Nullable Types

Kuzo has explicit nullable types. Append ? to any type to make it nullable — it can hold null or a value of the base type.

val a: i32? = null
val b: i32? = 42

Use ?? (coalescing) to provide a default for null values:

val x: i32? = null
val y = x ?? 99

val chain = null ?? null ?? 7 ?? -1

?? returns the first non-null value. Chain multiple ?? for fallback sequences.

Use ! to assert non-null (panics if null) and ?. for safe field access:

type Addr = Addr(city: str, zip: i32)
type User = User(name: str, addr: Addr?)

val user = User("Alice", Addr("Beijing", 100000))
val city = user?.addr?.city

val some: i32? = 42
val forced = some!

?. short-circuits to null if any link in the chain is null. ! unwraps a non-null value — use it when you're certain the value exists.

Tip

Prefer ?? for safe defaults. Use ! sparingly — it's an assertion that crashes if the value is null.

Newtype

Newtype creates a type-safe wrapper around an existing type. Even if two newtypes share the same underlying type, they are not interchangeable.

type Celsius = Celsius(f64)
type Fahrenheit = Fahrenheit(f64)

val c = Celsius(100.0)
val f = Fahrenheit(100.0)

You can't accidentally pass Celsius where Fahrenheit is expected — the compiler enforces type safety even though both wrap f64.

Unwrap newtype values with pattern matching:

fun toFahrenheit(c: Celsius): Fahrenheit {
    match c {
        Celsius(v) => Fahrenheit(v * 9.0 / 5.0 + 32.0)
    }
}

Newtypes are great for domain modeling — UserId, Email, Meters — without the overhead of a full record.

type UserId = UserId(i64)
type Email = Email(str)

val uid = UserId(42i64)
val email = Email("test@example.com")

Type Casting

Use cast(value).to(Type) to convert between types. Kuzo supports widening, narrowing, and cross-category conversions.

Widening

val wide = cast(42i8).to(i64)
val u16v = cast(200u8).to(u16)

Narrowing with wrapping

val wrapped = cast(300i32).to(i8)
val negToU8 = cast((-1i32)).to(u8)

Narrowing casts wrap around — 300i32 to i8 gives 44 (300 mod 256 - 256).

Int ↔ Float

val f = cast(42i32).to(f64)
val i = cast(3.99f64).to(i32)

Float-to-int truncates (3.99 becomes 3). Int-to-float is exact for representable values.

Char ↔ Int

val code = cast('A').to(i32)
val ch = cast(65i32).to(char)

Int → Str

val s = cast(42i32).to(str)
val b = cast(true).to(str)

Cast to str converts any primitive to its string representation. cast(true).to(str) returns "true".

Tip

Chain casts for complex conversions: cast(cast(65i32).to(i64)).to(i8).

Operators

Kuzo supports standard arithmetic, comparison, logical, and bitwise operators.

Arithmetic

val a = 1 + 2 * 3
val b = (1 + 2) * 3
val c = 100 / 7
val d = 100 % 7

Operator precedence follows standard math rules: * and / before + and -. Integer division truncates toward zero.

Comparison & Logical

val eq = 5 == 5
val lt = 3 < 7
val both = (5 > 3) && (2 < 8)
val either = (1 > 2) || (3 < 4)

Bitwise

val and = 0xFF & 0x0F
val or = 0xF0 | 0x0F
val xor = 0xFF ^ 0x0F
val not = ~0
val shifted = 1 << 4
val shifted_right = 256 >> 4

Bitwise operators work on integer types. Hex (0xFF), binary (0b1010), and octal (0o777) literals are supported.

val hex = 0xFF
val bin = 0b1010
val oct = 0o777

Tip

Bitwise & has higher precedence than |, matching C convention. Use parentheses for clarity.

Error Handling

Kuzo uses Throw<T, E> types for explicit error handling.

fun safeDiv(a: i32, b: i32): Throw<i32, Error> {
    if b == 0 {
        throw Error("division by zero")
    }
    Ok(a / b)
}

The return type Throw<i32, Error> tells callers that this function either succeeds with an i32 or fails with an Error.

Tip

Unlike exceptions in other languages, Kuzo errors are visible in the function signature. You always know what can go wrong.

Use ? to propagate errors — if the expression fails, the function returns immediately with the error:

fun step1(a: i32): Throw<i32, Error> {
    if a < 0 { throw Error("negative") }
    Ok(a + 1)
}

fun pipeline(a: i32): Throw<i32, Error> {
    val r1 = step1(a)?   // propagates error if step1 fails
    Ok(r1 * 2)
}

Define error subtypes with : Err for granular error matching:

type NotFound: Err = NotFound(msg: str)
type Timeout: Err = Timeout(msg: str)

fun lookup(id: i32): Throw<str, Error> {
    if id < 0 { throw NotFound("negative id") }
    if id == 0 { throw Timeout("timed out") }
    Ok("user-" + cast(id).to(str))
}

Match on different error subtypes in multiple arms:

match lookup(-1) {
    Ok(name) => println("found: {name}")
    Error(NotFound(m)) => println("not found: {m}")
    Error(Timeout(m)) => println("timeout: {m}")
    Error(_) => println("other error")
}

Use ?? to provide defaults for Throw values, just like nullable types:

val result = safeDiv(10, 0) ?? -1
// result = -1 (safeDiv throws, ?? provides default)

Tip

throw can throw any type — not just Error. Use throw 42 or throw "message" for lightweight error signaling.

Async & Channels

Kuzo has built-in async/await support and typed channels for concurrent programming.

Async functions

async fun fetch(): Async<i32> {
    Timer(1).await()
    42
}

The async keyword marks a function as asynchronous. await() suspends execution until the operation completes. Async<T> is the return type for async functions.

Channels

val ch = channel<i32>(2)

ch.send(10)
ch.send(20)

val first = ch.recv()   // 10
val second = ch.recv()  // 20

Channels are typed communication pipes between concurrent tasks. channel<i32>(2) creates a buffered channel that holds up to 2 integers. send writes a value, recv reads one.

Tip

Channels make concurrent code safe — no shared mutable state, just message passing.

Async functions can chain — one async function can await another:

async fun fetchValue(): Async<i32> {
    Timer(1).await()
    42
}

async fun process(): Async<i32> {
    val v = fetchValue().await()
    v + 100
}

val result = process().await()  // 142

Channels work with any type — records, ADTs, nullable values, and more:

val ch = channel<Point>(2)
ch.send(Point(1, 2))
ch.send(Point(3, 4))

val p1 = ch.recv()  // Point(1, 2)
val p2 = ch.recv()  // Point(3, 4)

// Nullable values through channels
val nch = channel<i32?>(2)
nch.send(10)
nch.send(null)
val v1 = nch.recv()  // 10
val v2 = nch.recv()  // null

Defer

defer schedules a statement to run when the function exits, regardless of how it exits. Deferred statements run in LIFO (last-in, first-out) order.

fun process(): void {
    defer println("cleanup")
    defer println("second cleanup")
    println("working")
}

When process is called, it prints: working, then second cleanup, then cleanup. The last deferred statement runs first.

Defer is useful for resource cleanup:

fun readFile(path: str): str {
    val ch = open(path)
    defer ch.close()
    ch.read()
}

No matter how readFile exits — normal return, early return, or error — the channel is always closed.

Tip

Deferred statements capture variable values at the time of execution, not at the time of defer. If a variable changes after defer, the deferred statement sees the new value.

Defer runs even when a function exits via throw — making it ideal for cleanup in error paths:

fun riskyOp(): Throw<i32, Error> {
    defer println("cleanup always runs")
    if true { throw Error("fail") }
    Ok(1)
}
// "cleanup always runs" is printed even though throw occurs

In recursive functions, each call's defers execute in LIFO order as the stack unwinds:

fun recurse(n: i32): i32 {
    defer println("defer {n}")
    if n <= 0 { 0 } else { n + recurse(n - 1) }
}
// recurse(2) prints: defer 0, defer 1, defer 2

Strings

Kuzo supports string interpolation with {} syntax. Any expression can be embedded inside a string.

val name = "Kuzo"
val version = 1

println("Welcome to {name} v{version}")
println("sum = {1 + 2}")
println("point = {Point(3, 4)}")

Place expressions inside {} within a string literal. Kuzo evaluates them at runtime and converts the result to a string.

String Operations

Strings support indexing, length, concatenation, and comparison:

val s = "hello"
val first = s[0]      // 'h' (char)
val len = s.len()      // 5
val concat = "ab" + "cd"  // "abcd"
val mixed = "n=" + 42    // "n=42" (str + int)

String comparison is lexicographic and Unicode-aware:

val a = "apple" < "banana"  // true
val b = "abc" < "abcd"      // true (shorter prefix)

Escape Sequences

val tab = "\t"           // tab
val newline = "\n"        // newline
val quote = "\""          // embedded quote
val backslash = "\\"       // literal backslash
val unicode = "\u{1F600}"  // emoji
val nul = "\0"            // NUL character

Unicode Support

Strings are Unicode-aware. Indexing returns a char by codepoint:

val emoji = "😀😁😂"
val len = emoji.len()    // 3 (one codepoint each)
val first = emoji[0]    // '😀'

val cjk = "你好"
val ch = cjk[0]         // '你'

Tip

Nullable strings work with ??: (nullableStr ?? "default") provides a fallback for null.
